១. របៀបប្រើទំព័រដើម
Using the Home Page

  1. បើកម៉ឺនុយ៖ ចុចសញ្ញាបន្ទាត់បីនៅជ្រុងខាងស្តាំ ដើម្បីមើលតំណភ្ជាប់សំខាន់ៗ។
  2. ពិនិត្យកាលបរិច្ឆេទ៖ មើលពេលវេលារាប់ថយក្រោយ និងថ្ងៃផុតកំណត់នៅលើផ្ទាំងកម្មវិធី។
  3. ចុះឈ្មោះ៖ ចុចប៊ូតុងពណ៌ទឹកក្រូច «ចុះឈ្មោះឥឡូវនេះ»។
  4. ទទួលព័ត៌មាន៖ ចុច «ចូលឆាណែលតេឡេក្រាមកម្មវិធី» ដើម្បីទទួលដំណឹងថ្មីៗ។
  5. អូសចុះក្រោម៖ មើលរង្វាន់ សេចក្តីជូនដំណឹង និងព័ត៌មានលម្អិតរបស់កម្មវិធី។

២. របៀបចុះឈ្មោះ
Registration Guide

  1. ជ្រើសរើសប្រភេទចុះឈ្មោះ បុគ្គល / Individual ឬ ក្រុម / Team។
  2. បើជាក្រុម ជ្រើសរើសសមាជិកសរុប ២ ឬ ៣ នាក់។
  3. បំពេញព័ត៌មានទាំងអស់របស់បេក្ខជនម្នាក់ៗ៖ ឈ្មោះខ្មែរ ឈ្មោះឡាតាំង ភេទ សញ្ជាតិ កម្រិតសិក្សា ឆ្នាំសិក្សា មុខជំនាញ ស្ថាប័ន ទូរស័ព្ទ និងអ៊ីមែល។
  4. បញ្ចូលរូបភាព ឬ PDF កាតសម្គាល់និស្សិតរបស់សមាជិកម្នាក់ៗ។
  5. ពិនិត្យព័ត៌មាន រួចចុចបញ្ជូន។ រក្សាទុកលេខចុះឈ្មោះដែលបង្ហាញក្រោយបញ្ជូនជោគជ័យ។
  6. ពិនិត្យអ៊ីមែលបញ្ជាក់ និងចូលឆាណែល Telegram តាមប៊ូតុងនៅលើទំព័រជោគជ័យ។

ចំណាំ៖ មិនចាំបាច់បង្កើតពាក្យសម្ងាត់ ឬចូលគណនីឡើយ។ ត្រូវប្រើអ៊ីមែលដែលអាចទទួលសារបាន។

បើកទម្រង់ចុះឈ្មោះ

៣. របៀបបញ្ជូនស្នាដៃ
Submit Research Document

  1. បើកទំព័រ «ដាក់បញ្ជូនឯកសារ» ពីម៉ឺនុយ។
  2. ជ្រើសរើសបញ្ជូនជា បុគ្គល ឬ ក្រុម។ ក្រុមអាចមានសមាជិករហូតដល់ ៣ នាក់។
  3. បំពេញឈ្មោះ ភេទ អ៊ីមែល លេខទូរស័ព្ទ និងចំណងជើងស្នាដៃតាមដែលទម្រង់ស្នើសុំ។
  4. ជ្រើសឯកសារស្រាវជ្រាវពីទូរស័ព្ទ ហើយពិនិត្យឈ្មោះឯកសារមុនបញ្ជូន។
  5. ចុចបញ្ជូន ហើយរង់ចាំរហូតទំព័របង្ហាញសារជោគជ័យ។ កុំបិទទំព័រពេលកំពុងផ្ទុកឡើង។

សូមត្រៀមមុន៖ ប្រើអ៊ីនធឺណិតមានស្ថិរភាព និងដាក់ឈ្មោះឯកសារឱ្យច្បាស់លាស់។

បើកទម្រង់បញ្ជូនឯកសារ

៤. របៀបប្រើបណ្ណាល័យ
Using the Document Library

  1. បើក «បណ្ណាល័យឯកសារទេសចរណ៍» ពីម៉ឺនុយទំព័រដើម។
  2. ឯកសារទាំងអស់នឹងបង្ហាញជាកាត និងមានរូបមើលជាមុននៃទំព័រទី១ ប្រសិនបើ Google Drive គាំទ្រ។
  3. វាយពាក្យគន្លឹះ ឬចំណងជើងឯកសារក្នុងប្រអប់ស្វែងរក។ លទ្ធផលនឹងផ្លាស់ប្តូរដោយស្វ័យប្រវត្តិ។
  4. ចុចលើកាតឯកសារ ឬប៊ូតុង View ដើម្បីបើកឯកសារនៅ Google Drive។
  5. ក្នុង Google Drive អ្នកអាចអាន ពង្រីក ចែករំលែក ឬទាញយក ប្រសិនបើម្ចាស់ឯកសារបានអនុញ្ញាត។
  6. ចុចសញ្ញា × នៅក្បាលទំព័រ ដើម្បីត្រឡប់ទៅទំព័រដើម។

បើរូបទំព័រទី១មិនបង្ហាញ៖ រង់ចាំបន្តិច ឬចុច View ដើម្បីបើកឯកសារផ្ទាល់។ ឯកសារខ្លះមិនមានរូបមើលជាមុនទេ។
